# 個人筆記系統 功能規格書

> 本文件為專案原始需求規格。實作狀態請見 [`README.md`](../README.md#status)。

## 1. 產品概述

類 Notion 的個人筆記與知識管理工具，以區塊式編輯器為核心，提供網頁版與（後續）手機 App。

- 專案性質：全開源專案，任何人皆可自行架設（Self-hosted）、修改與貢獻
- 使用對象：個人使用，無工作區、團隊、角色權限
- 分享方式：僅供他人唯讀檢視（預留，暫不實作）
- 不包含：資料庫、頁面範本、協作編輯、留言、AI、第三方整合、付費、提醒、備份、新手引導、管理後台

## 2. 狀態標記說明

| 標記   | 意義                                       |
| ------ | ------------------------------------------ |
| `MVP`  | 第一版必須實作                             |

| `預留` | 暫不實作，但架構與資料結構需先預留擴充空間 |

### 3.5 分享（僅供檢視）

整個模組為 `預留`，第一版不實作。

| 功能               | 狀態   | 說明                                 |
| ------------------ | ------ | ------------------------------------ |
| 產生唯讀分享連結   | `預留` | 分享對象僅能檢視，不可編輯、不可留言 |
| 分享開關           | `預留` | 可隨時關閉連結                       |
| 連結到期時間       | `預留` |                                      |
| 密碼保護           | `預留` |                                      |

預留事項：

- 頁面資料表預留分享相關欄位，或規劃獨立的分享連結資料表（token、到期時間、密碼雜湊、是否啟用）
- 頁面渲染元件需能以「唯讀模式」呈現，方便未來重用於分享頁
- 權限判斷集中處理，避免之後加入分享時需大幅修改

## 5. 開源專案規範

### 5.1 授權條款

授權條款待決定，常見選項：

| 授權       | 特性                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| MIT        | 最寬鬆，他人可自由使用、修改、閉源商用                                                     |
| Apache 2.0 | 與 MIT 類似，另含專利授權條款                                                              |
| AGPL-3.0   | 他人若修改後架設成網路服務提供他人使用，必須公開修改後的原始碼，可防止被閉源包裝成商業服務 |

- 所有使用的第三方套件，授權需與本專案授權相容
- 避免使用閉源或需付費授權的套件

### 5.2 自行架設（Self-hosted）

| 項目                             | 狀態   | 說明                                                         |
| -------------------------------- | ------ | ------------------------------------------------------------ |
| Docker / Docker Compose 一鍵部署 | `MVP`  | 包含前端、後端、資料庫                                       |
| 環境變數設定                     | `MVP`  | 所有設定透過環境變數，提供 `.env.example`                    |
| 檔案儲存可切換                   | `MVP`  | 至少支援本機儲存，預留 S3 相容儲存（如 MinIO）               |
| Email 寄送可切換                 | `預留` | 使用標準 SMTP，配合忘記密碼、Email 驗證功能                  |
| 第三方登入可選                   | `預留` | Google、Apple 登入需由架設者自行設定金鑰，未設定時隱藏該選項 |
| 資料庫 migration                 | `MVP`  | 升級版本時可自動更新資料結構                                 |

原則：

- 不可綁定任何特定雲端服務，核心功能需能在單台主機上完整運作
- 程式碼中不得寫死任何金鑰、密碼、網域

### 5.5 對其他功能的影響

- 多語系介面：開源專案較可能有國際使用者，文字一開始就應抽出，方便社群貢獻翻譯
- 公開 API：開源後需求較高，API 設計應保持清楚一致
- 程式碼註解與文件建議使用英文，較容易吸引國際貢獻者；介面語言則不受影響

## 6. 注意事項

- 第一版不含「忘記密碼」，使用者忘記密碼將無法自行找回，測試與初期使用需留意
- 刪除頁面建議一開始就採軟刪除，未來加入垃圾桶功能時不需修改資料結構
- 授權條款應在第一次公開程式碼前確定，之後更改需取得所有貢獻者同意
